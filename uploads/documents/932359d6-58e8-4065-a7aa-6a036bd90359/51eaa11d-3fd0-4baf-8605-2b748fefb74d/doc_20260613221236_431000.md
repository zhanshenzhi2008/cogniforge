# 仓库拆分操作文档

## 目标

将 `llm-agent` 仓库中的 6 个模块拆分到新仓库 `llm-agent-framework`，保留 Git 历史。

---

## 拆分清单

| 模块 | 操作 |
|------|------|
| agent-common | 拆分到新仓库 |
| agent-common-lite | 拆分到新仓库 |
| agent-auth | 拆分到新仓库 |
| agent-extension | 拆分到新仓库 |
| agent-runtime | 拆分到新仓库 |
| agent-runtime-starter | 拆分到新仓库 |

| 模块 | 操作 |
|------|------|
| agent-platform | 保留在 llm-agent |
| agent-platform-starter | 保留在 llm-agent |

---

## 操作步骤

### 步骤1：复制仓库

在 `F:\app\project\` 下执行（不是 `F:\gientech-repository\`，避免和现有仓库冲突）：

```bash
cd F:/app/project
xcopy /E /I /H /Y F:\gientech-repository\llm-agent F:\app\project\llm-agent-framework
```

### 步骤2：安装 git-filter-repo（如已安装跳过）

```bash
git clone https://github.com/newren/git-filter-repo.git
python git-filter-repo/install.py
```

或使用 pip：

```bash
pip install git-filter-repo
```

### 步骤3：裁剪新仓库历史（只保留6个模块）

进入新仓库目录：

```bash
cd F:/app/project/llm-agent-framework
```

执行 filter-repo，只保留需要的 6 个目录：

```bash
git filter-repo --path agent-common --path agent-common-lite --path agent-auth --path agent-extension --path agent-runtime --path agent-runtime-starter --force
```

> 执行后，历史会被重写，只保留涉及这 6 个目录的提交。

### 步骤4：配置新仓库 remote

```bash
git remote set-url origin <新仓库地址>
```

### 步骤5：推送到新仓库

```bash
git push -u origin --all
git push -u origin --tags
```

### 步骤6：回到老仓库，删除 6 个模块

回到原始 `llm-agent` 仓库，删除这 6 个目录：

```bash
cd F:/gientech-repository/llm-agent
git rm -r agent-common agent-common-lite agent-auth agent-extension agent-runtime agent-runtime-starter
```

### 步骤7：提交拆分记录

```bash
git commit -m "拆分: 将通用模块移至 llm-agent-framework 仓库"
git push origin <分支名>
```

---

## 验证

### 新仓库验证
```bash
cd F:/app/project/llm-agent-framework
git log --oneline | head -20
git log --oneline --follow -- agent-common | head -10
```

### 老仓库验证
```bash
cd F:/gientech-repository/llm-agent
git status
git log --oneline | head -5
```

---

## 说明

- **步骤1**：复制仓库副本（包含 .git 历史）
- **步骤2**：确保有 filter-repo 工具
- **步骤3**：用 filter-repo 重写历史，只保留 6 个模块相关提交
- **步骤4~5**：将裁剪后的仓库推送到新 remote
- **步骤6~7**：清理老仓库，提交拆分记录

> 注意：拆分后 commit hash 会变化，这是正常现象。
